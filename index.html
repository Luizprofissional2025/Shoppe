Gerador de Promoções

Crie uma arte para divulgar seus links de afiliado

1. Dados do produto

O link será incluído na mensagem de divulgação. A leitura automática dos dados depende de uma integração autorizada com a Shopee.
Escolha a foto do produto no seu dispositivo para colocá-la na arte.
Preencha os dados e clique em “Gerar promoção”.

2. Prévia da promoção

O compartilhamento abre o WhatsApp para você confirmar o envio. O site não dispara mensagens automaticamente.
Protótipo inicial: a arte é gerada no navegador. A importação automática de nome, preço e foto pelo link da Shopee ainda precisa de uma integração/API autorizada; este protótipo permite informar os dados manualmente.
