Gerador de Promoções

Crie artes e mensagens para divulgar seus links de afiliado 🛍️

🛍️ 1. Dados do produto

A busca automática exige um link da Shopee que permita identificar o ID do produto e acesso ativo à API de afiliados. O preenchimento manual continua disponível.
Escolha uma foto do produto para incluí-la na arte promocional.
Preencha os dados e clique em “Gerar promoção”.

🎨 2. Prévia da promoção

No computador, o botão abre o WhatsApp Web com a mensagem e o link. A imagem é baixada separadamente para você anexar na conversa. O navegador não permite anexar automaticamente um arquivo local ao WhatsApp Web.

💬 3. Mensagem promocional

O link de afiliado aparece como link clicável na mensagem do WhatsApp.

    Cada mensagem vai com o texto e o link de afiliado; o WhatsApp mostra sozinho o cartão com a foto e o título do produto, como nas suas conversas. Clique em “Enviar todas pelo WhatsApp”: a primeira abre pronta, você escolhe a conversa/grupo e envia; depois o mesmo botão abre a próxima, até acabar. O WhatsApp não permite que um site envie várias mensagens sozinho — por isso a confirmação em cada uma.

    🤖 Envio automático para o seu WhatsApp (1 clique)

    1. Uma única vez: arraste este botão para a barra de favoritos do navegador (Ctrl+Shift+B mostra a barra): 📌 Enviar promoções
    2. Seu número com DDI e DDD, para abrir a conversa “Você” direto (opcional):
    3. — copia as mensagens e abre o WhatsApp Web.
    4. Na aba do WhatsApp, abra a conversa de destino e clique no favorito “Enviar promoções”. Ele pede uma confirmação (mostrando o nome da conversa) e envia cada promoção como uma mensagem separada, com intervalo de alguns segundos.
    Automação não oficial do WhatsApp Web: para o seu próprio chat o risco é baixo, mas não é zero, e mudanças no layout do WhatsApp podem exigir ajuste. O script para sozinho se algo não funcionar, informando em qual mensagem parou.
    A busca automática depende de acesso autorizado à API de afiliados da Shopee. Dados ausentes podem ser preenchidos manualmente. O compartilhamento não envia mensagens automaticamente: cada envio é confirmado por você.
