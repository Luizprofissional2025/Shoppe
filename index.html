Gerador de Promoções

Crie artes e mensagens para divulgar seus links de afiliado 🛍️

🛍️ 1. Dados do produto

A busca automática exige um link da Shopee que permita identificar o ID do produto e acesso ativo à API de afiliados. O preenchimento manual continua disponível.
Escolha uma foto do produto para incluí-la na arte promocional.
Preencha os dados e clique em “Gerar promoção”.

🎨 2. Prévia da promoção

No computador, o botão abre o WhatsApp Web com a mensagem e o link. A imagem é baixada separadamente para você anexar na conversa. O navegador não permite anexar automaticamente um arquivo local ao WhatsApp Web.

💬 3. Mensagem promocional

O link de afiliado aparece como link clicável na mensagem do WhatsApp.
A busca automática depende de acesso autorizado à API de afiliados da Shopee. Dados ausentes podem ser preenchidos manualmente. O compartilhamento não envia mensagens automaticamente.
